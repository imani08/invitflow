# Archive documentaire

Cet espace conserve uniquement les artefacts documentaires de première génération qui ont été remplacés dans les emplacements de publication actifs.

- [`legacy-docx/`](legacy-docx/README.md) décrit les 16 premiers exports Word, leurs sources et les fichiers canoniques correspondants.
- [`legacy-adr/`](legacy-adr/README.md) conserve l’index ADR historique et les décisions dont le contenu utile a été comparé puis fusionné dans `docs/adr/` ou les documents d’architecture actuels.

Les références canoniques sont les 16 Word à la racine de `docs/dist/docx/` et les 12 ADR dans `docs/adr/`. Les fichiers archivés ne sont plus la documentation de référence.
