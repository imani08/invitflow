# ADR 0009 — Tokens de thème InvitaFlow

Version: 1.0
Status: Living document
Last updated: 2026-10-07
Owner: FOCUS HD ENTREPRISES
Product: InvitaFlow
Status: **ACCEPTED — implémentation observée, conformité non vérifiée**

## Contexte

Le produit doit conserver un choix d’architecture explicite et traçable à partir du dépôt courant.

## Décision

Conserver des variables sémantiques partagées pour surfaces/texte/thèmes.

## Conséquences

Contraste cohérent; chaque page reste à auditer automatisé + humain.
