## 2. Données pouvant être traitées

Selon les fonctions utilisées, InvitaFlow peut traiter :

- données de compte : nom, e-mail, téléphone, identifiant, préférences et rôles ;
- données d’événement : nom, type, dates, lieux, cérémonies, tables, zones et paramètres ;
- données d’invités : nom, téléphone, e-mail, table, cérémonie, RSVP, check-in, QR code ou identifiant d’invitation ;
- médias : photos, logos, visuels, textes et fichiers importés ;
- données de paiement : référence, montant, devise, statut, pack, transaction et informations de réconciliation ;
- données techniques : adresse IP, journaux de sécurité, type d’appareil ou navigateur, timestamps, session, erreurs et traces techniques.

## 3. Finalités

Ces données servent à fournir le service, créer les invitations, gérer RSVP et check-in, sécuriser les comptes, prévenir les abus, traiter et vérifier les paiements, fournir le support, améliorer la fiabilité et respecter les obligations légales applicables.

## 4. Origine des données d’invités

Les données d’un invité peuvent être fournies par l’invité lui-même ou importées par l’organisateur. L’organisateur doit s’assurer qu’il est autorisé à les utiliser.

## 5. Fondements

Selon le contexte, les traitements reposent notamment sur l’exécution du service demandé, la sécurité, les obligations légales, l’intérêt légitime à prévenir la fraude et, lorsque requis, le consentement.
